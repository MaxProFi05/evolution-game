# Skywild Evolution

## Структура
- `index.html` — главная страница
- `css/style.css` — внешний вид
- `js/data.js` — карта и эволюции
- `js/game.js` — механики игры
- `assets/sprites/` — оригинальные SVG-спрайты эволюций
- `assets/world/map.json` — данные карты

## Загрузка на GitHub
Загрузи **всё содержимое папки** в корень репозитория `evolution-game`.
В GitHub Pages выбери:
- Branch: `main`
- Folder: `/(root)`

После публикации сайт откроется по адресу:
`https://maxprofi05.github.io/evolution-game/`
